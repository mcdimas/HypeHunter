# Hype Hunter

Hype Hunter — self-hosted рабочее пространство для Reels и Threads. Добавляйте конкурентов, находите удачные публикации, работайте с переводами и адаптируйте идеи под свой бизнес. Собственные тексты и даты публикаций — в одном контент-плане.

**[Открыть Hype Hunter](https://hypehunter.ru) · [Исходный код](https://github.com/mcdimas/HypeHunter) · [Установка](docs/self-hosting.md)**

Путь пользователя: лендинг → вход через Telegram / Яндекс ID → конкуренты → библиотека Reels и Threads → перевод и редактор → доска или календарь → самостоятельная публикация.

## Возможности

- Reels и Threads: импорт, поиск, фильтры и показатели загруженных материалов.
- Оригиналы, переводы и собственные правки хранятся раздельно.
- Редактор с автосохранением и защитой от конфликтующих изменений.
- Контент-план: доска этапов и недельный календарь.
- Личные аккаунты, изоляция данных и приватных медиа, управление сеансами.
- Вход без пароля через Telegram: код из исходного браузера и явное подтверждение в боте.

Яндекс ID включается через YANDEX_CLIENT_ID. Email-коды, подписки и оплата пока не подключены. Автопубликации нет: пользователь публикует материал самостоятельно. Цены на лендинге описывают будущие тарифы.

## Стек

- Frontend: HTML, CSS и обычный JavaScript; без React и frontend-фреймворка.
- Backend: FastAPI + SQLModel + Alembic, PostgreSQL 17.
- Интеграции: Apify для импорта, Telegram Bot API для входа, Codex CLI для переводов при отдельной настройке.
- Инфраструктура: Docker Compose, Caddy и Nginx. Без Redis, отдельного сервиса авторизации и очереди Celery.

## Self-hosting: быстрый старт

Нужны Docker Compose, домен с HTTPS и собственный Telegram-бот. Для импорта нужен Apify; переводы требуют отдельно настроенного Codex CLI.

```bash
git clone https://github.com/mcdimas/HypeHunter.git
cd HypeHunter
cp .env.example .env
# Заполните секреты, PUBLIC_ORIGIN и проверенный OWNER_TELEGRAM_ID.
# Настройте HTTPS reverse proxy по инструкции ниже.
docker compose up -d --build
```

Внутренний HTTP-вход: `127.0.0.1:3300`. Открывайте приложение через свой HTTPS-домен: cookie сессии всегда Secure. Миграции выполняются при старте API. PostgreSQL не публикуется наружу.

**Полная инструкция:** [настройка, Telegram, переводы, обновления и резервные копии](docs/self-hosting.md). Не запускайте публичный экземпляр до настройки секретов и HTTPS.

## Разработка и тесты

```bash
npm ci
npm test
npm run dev
```

`npm run dev` обслуживает frontend; это не замена полноценному backend и HTTPS-входу.

```bash
python3.12 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements-dev.txt
cd backend
pytest -q
```

На Windows используйте `.venv\Scripts\Activate.ps1`. PostgreSQL-проверки миграций и конкурентных запросов требуют отдельной тестовой БД: [подробнее](docs/self-hosting.md#проверки). [Шаблон CI](docs/ci.yml) запускает frontend, backend и PostgreSQL-тесты без production-секретов; для включения перенесите его в `.github/workflows/ci.yml`. В этом публичном репозитории workflow пока не активирован.

## Карта репозитория

| Путь | Содержимое |
| --- | --- |
| `app.js`, `ui/`, `styles.css` | Приложение, лендинг, профиль, библиотека и редактор |
| `backend/app/` | API, авторизация, модели, импорт и переводы |
| `backend/alembic/` | Миграции и перенос владения данными |
| `backend/tests/`, `tests/` | Серверные и frontend-тесты |
| `assets/` | Публичные иллюстрации; не пользовательские медиа |
| `compose.yaml`, `Caddyfile`, `nginx.conf` | Самостоятельное развёртывание |

Это публичный снимок актуальных исходников. `SOURCE_REVISION` указывает исходную ревизию. История внутренней разработки, пользовательские данные, секреты и production-деплой сюда не включены.

## Вклад

Предложения и исправления приветствуются: fork → отдельная ветка → pull request. Сохраняйте минимальный стек и разделение оригиналов, переводов и правок. Перед PR запустите `npm test` и backend-тесты; не добавляйте секреты, реальные данные пользователей или платные интеграционные вызовы в тесты.

О проблемах безопасности сообщайте непублично по [SECURITY.md](SECURITY.md).
